Setup used by the examples 
library(nmpilot)
# Copy the example project to a temporary folder (runs write files there)
file.copy(system.file("extdata", "example", package = "nmpilot"),
          tempdir(), recursive = TRUE)
ex   <- file.path(tempdir(), "example")
nmfe <- "C:/nm76g64/run/nmfe76.bat"   # path to your nmfe launcher

Examples that only read results need ex; examples that run NONMEM also need nmfe. Objects such as dat, s, runs or cmp are created by earlier tasks of the guide.

Read and standardise a dataset

nm_read_csv

Reads a NONMEM CSV file, recognises the reserved columns (ID, TIME, DV, AMT, EVID, MDV, CMT...), converts '.' to missing values, computes the relative time, the time after dose (TAD) and the dose-normalised DV, and flags BLQ records.

Help in R: ?nm_read_csv

dat <- nm_read_csv(file.path(ex, "example_data.csv"))
head(dat$data)     # standardised data
dat$mapping        # reserved labels -> original column names

Suggest a structural model and initial values

nm_suggest_model plot.nm_model_suggestion

Analyses the data before any NONMEM run and ranks candidate models (compartments, input, elimination, residual error), each with initial values for THETA, IIV and SIGMA and alerts on what no candidate describes.

Help in R: ?nm_suggest_model, ?plot.nm_model_suggestion

s                       # ranked candidates, initial values, alerts
plot(s, "profiles")
plot(s, "support")

Expected precision of the design

nm_suggest_design

Expected RSE of the parameters and eta-shrinkage of a candidate for the sampling design of the dataset or for another design, from the population Fisher information matrix.

Help in R: ?nm_suggest_design

nm_suggest_design(s, candidate = 1)
# sparse design: 3 samples, 100 subjects
nm_suggest_design(s, times = c(1, 4, 12), n_subjects = 100)

Run the top candidates

nm_suggest_run

Writes the control streams of the chosen candidates, runs them with nm_run(), reads their OFV and ranks them by BIC.

Help in R: ?nm_suggest_run

                    candidates = 1:3, n_cores = 3)

Write a control stream

nm_write_ctl

Writes a complete control stream for a compartmental PK model (1 to 3 compartments, IV or extravascular, first-order, zero-order or transit absorption, linear or Michaelis-Menten elimination), possibly from a candidate of nm_suggest_model().

Help in R: ?nm_write_ctl

# or from the dataset columns

MU referencing

nm_ctl_mu

Rewrites log-normal parameters as MU_m = LOG(THETA(n)) and P = EXP(MU_m + ETA(m)), as required by EM and Bayesian methods (SAEM, IMP, BAYES).

Help in R: ?nm_ctl_mu

nm_ctl_mu(ctl)
nm_ctl_mu(ctl, parameters = c("CL", "V"), mode = "linear")

Inter-occasion variability

nm_ctl_iov

Adds IOV to chosen parameters with $ABBR REPLACE and $OMEGA BLOCK SAME; the occasion item must be in $INPUT.

Help in R: ?nm_ctl_iov

M3 method for BLQ data

nm_ctl_m3

Applies the M3 method (Beal 2001): BLQ observations contribute P(DV < LLOQ); the LLOQ is a constant, a dataset column or depends on the analytical method.

Help in R: ?nm_ctl_m3

cols <- c("ID", "TIME", "AMT", "DV", "EVID", "MDV", "CMT", "OCC", "BQL")
ctl  <- nm_write_ctl(input = cols, error = "combined")
nm_ctl_m3(ctl, bql = "BQL", lloq = 0.02)

Optimise a base model without iterative runs

nm_derivatives_ctl nm_optimize_base plot.nm_optimize_base

Ranks the possible changes of a base model (residual error, random effects, covariates) by their expected dOFV, from its outputs (level 1) and one NONMEM evaluation run (level 2, linearised model).

Help in R: ?nm_derivatives_ctl, ?nm_optimize_base, ?plot.nm_optimize_base

nm_run(basename(p), nmfe, dirname(p))

o
plot(o)

Covariate effects on ETAs (Wasserstein)

Compares the distribution of an ETA between covariate groups with the Wasserstein distance and a permutation test, with the Wasserstein R2 between runs (Simon et al., Front Pharmacol 2026).
